# My Portfolio Website

This is my personal portfolio website, **built step-by-step while learning full stack development** with help from an AI assistant.  
We add one small feature every day and upload changes to GitHub.

## Features (so far)

- Home section with introduction
- About section for my background
- Projects section (to be expanded)
- Contact section (to be expanded)
- Responsive navigation bar

## Tech Stack

- HTML5
- CSS3 (custom styles)
- JavaScript (will add interactivity soon)

## How to View

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Or use **Live Server** extension in VS Code for auto-reload.

## Project Journey

- **Day 1**: Basic HTML structure, sections, and simple CSS layout.
- **Day 2**: (Coming soon) Improve Home and About sections.
- **Future**: Add JavaScript, backend with Node/Express, database, deployment.

## Learning Goals

- Master HTML/CSS/JS front-end
- Build backend (Node.js, Express)
- Database integration
- Deployment (Vercel/Netlify)
